Keyboard Shortcuts

  • Alt + Click — Edit block attributes
  • Delete / Backspace — Delete selected block
  • Alt + D — Duplicate selected block
  • Alt + E — Show tag example
  • Double-click on text — Edit text inline
  • Shift + Arrow Up / Arrow Down — Move selected block up / down
  • Alt + Z — Undo
  • Alt + Y — Redo
  • Escape — Close popups
